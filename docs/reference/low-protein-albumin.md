# 低总蛋白 / 低白蛋白：通用解读条目调研

Status: **IMPLEMENTED — independent medical review pending**（2026-11-05）

范围：面向所有成员（儿童与成人）的通用知识条目调研；年龄特异证据单独标注，不能互相外推。

> **实施状态（2026-11-05）：** 已按用户确认新增 `internal/analysis/knowledge/liver-low-protein-albumin.yaml`（`review.decision: accepted`，`review.note` 标注独立医学复核待补）。本文件 §4 文案是上线底稿；若独立医学复核调整文案，提升条目 `version` 并更新 review。§5.1 的 `rejected` 是调研阶段的占位示例，实际条目已按用户确认改为 `accepted`。

## 1. 决策问题与短答

1. **鉴别类别？** 肝合成减少、胃肠道丢失（PLE）、肾脏丢失（肾病综合征）、摄入不足/吸收不良、炎症、稀释或标本/检测波动；另有“总蛋白低而白蛋白正常”提示球蛋白偏低。见 §3、§8。
2. **“可能原因”怎么写？** 用“可能与……有关”“单次结果不能确定原因”，列可能性但不给诊断标签；不写“就是营养不良/肝病/肾病” [S2][S4][S6]。
3. **下一步写到什么程度？** 只写“带给医生、由医生判断是否复查、评估体重/营养、考虑尿蛋白”；不写检查套餐和治疗 [S2][S9][S14][S18]。
4. **生活建议？** 按本人年龄保证能量和蛋白质、不自行限蛋白、不用蛋白粉/增肌粉、监测体重（儿童可用生长曲线）、不因一次结果大幅改饮食 [S3][S12][S13][S14][S16]。
5. **不能说什么？** “白蛋白低=营养不良/肝病/肾病”“多吃蛋白/蛋白粉就能补”“每天吃 X 克”“要限蛋白”“水肿就是低蛋白造成的” [S3][S4][S5][S6][S9][S10][S11]。
6. **实现缺什么？** 触发只有 `any_flag_high`；`internal/contract/contract.go` 没有 `total_protein` / `albumin` 常量；识别端词典有总蛋白、白蛋白条目但没有 `analyte` 字段。均为工程缺口，不是医学结论。

## 3. 鉴别类别

| 类别 | 机制 / 场景 | 证据范围 | 依据 | 不能推出什么 |
| --- | --- | --- | --- | --- |
| 肝合成减少 | 白蛋白只在肝合成，半衰期约 3 周；慢性肝病可降低，急性肝病通常不低；PT/INR 更敏感。 | 通用（成人指南 + 儿童共识） | S2、S3、S6 | 不等于肝硬化/肝衰竭；不能判断急性肝损伤。 |
| 胃肠道丢失（PLE） | 黏膜损伤、淋巴管异常、Fontan 术后、感染、食物蛋白诱导等可致蛋白从肠道丢失；常低白蛋白、低总蛋白、低球蛋白。 | 通用 / 儿童 | S6、S7、S8 | 不能诊断 PLE；常需粪便 α1-抗胰蛋白酶等确认。 |
| 肾脏丢失（肾病综合征） | 肾病范围蛋白尿致白蛋白从尿丢失；诊断要求蛋白尿加低白蛋白或水肿。 | 成人 + 儿童 | S9、S10、S11、S18 | 没有尿蛋白不能成立；不能据此开始激素治疗。 |
| 摄入不足 / 吸收不良 | 长期能量-蛋白质不足或吸收不良影响体重和生长；但白蛋白不是营养状况的可靠指标，单纯饥饿时常正常；WHO 2023 对 <5 岁营养不良按人体测量与临床体征管理。 | 通用 / 儿童（WHO 仅 <5 岁） | S4、S5、S6、S17 | 低白蛋白不等于营养不良；不能靠白蛋白决定“补蛋白”。 |
| 炎症 / 急性疾病 | 白蛋白是负性急性期蛋白；细胞因子使合成下降、毛细血管通透性增加；球蛋白可升高，使总蛋白看似正常。 | 通用 / 成人 | S2、S4、S6 | 不能指出感染/炎症部位；不能说明急性或慢性。 |
| 稀释 / 标本 / 检测 | 液体负荷、输液侧采血、溶血/脂血/胆红素干扰、BCG/BCP 方法差异、参考区间人群差异可致假性结果；妊娠期血液稀释也可使蛋白偏低。 | 通用（妊娠证据为综述） | S1、S6 | 一次低值不是诊断；异常且意外时应复查。 |
| 孤立性低总蛋白 | 总蛋白=白蛋白+球蛋白；白蛋白正常时更可能反映球蛋白部分（丢失或合成减少）。 | 通用 | S6、S7、S8 | 不能归因于肝脏；不能诊断免疫缺陷。 |

**读法：** 低白蛋白而总蛋白正常并不矛盾——球蛋白升高可把总蛋白“撑”在正常范围；总蛋白低也不一定白蛋白低 [S6]。参考区间随年龄和检测方法变化：WS/T 780—2021 中 6 月–<13 岁白蛋白 39–54 g/L、13–18 岁 42–56 g/L；总蛋白 65–84、68–88 g/L [S1]。成人、妊娠期和老年人的参考范围或影响因素可能不同；单据范围优先，低于下限不等于疾病。

## 4. 通用文案草案

> **DRAFT — requires medical review。以下文字不得写入 `internal/analysis/knowledge/`，也不得进入生产 YAML。**

**explanation（可能原因）**

> 总蛋白由白蛋白和球蛋白组成，总蛋白低不一定代表白蛋白低。白蛋白偏低可能与肝脏合成减少、蛋白质从肠道或尿液丢失、营养摄入不足或炎症有关；单次结果不能确定原因，需要结合症状、体重变化和医生复查。

**check_directions（进一步检查 / 下一步）**

- 把结果和症状、近期体重变化、既往病史带给医生看，由医生判断是否复查。
- 医生可能根据情况安排尿蛋白检查。
- 如果同时有水肿、尿量明显减少或持续腹泻，请尽快让医生评估。

**general_advice（生活建议）**

- 按年龄和身体状况保持均衡饮食，不自行长期限蛋白。
- 不要自行使用蛋白粉或补充剂；是否需要补充由医生或营养师决定。
- 定期记录体重；儿童可记录生长曲线，复诊时带给医生。
- 不要因一次结果大幅改变饮食；先和医生确认原因。

> 红 flag 句（水肿、尿量减少、持续腹泻、体重下降、黄疸）属于安全提示，不是分级分诊；若产品坚持不做就医提示，可删除该句，仅保留“和医生讨论”。此句需产品与医学共同复核。

**track_items：** `[TP, ALB]`

**source_ids（主列表，通用/成人）：** `ACG 2017`、`Duvall 2023`、`ASPEN 2021`、`Ozen 2023`、`KDIGO 2021`、`WS/T 578.1—2017`、`中国居民膳食指南（2022）`

**source_ids（年龄特异，备注中标明）：** `WS/T 780—2021（仅儿童）`、`NICE NG75（仅儿童）`、`AAP 2016（儿童/青少年）`、`NASPGHAN/ESPGHAN 2019（仅儿童）`

> 成人补充剂与限蛋白建议为保守产品建议；直接证据来自儿童/青少年（S3、S16），不外推为成人疗效结论。

### 5.2 触发扩展（工程决定，不是医学主张）

当前 `internal/analysis/knowledge.go` 的 `knowledgeTrigger` 只有 `any_flag_high` 与 `all_normal`；`triggerMatches` 在 `AnyFlagHigh` 为空时直接返回 false；loader 也把 `any_flag_high` 设为必填。低值条目即使写了也不会加载/命中。

最小改动是增加对称字段：

```go
type knowledgeTrigger struct {
	Panel       string   `yaml:"panel"`
	AnyFlagHigh []string `yaml:"any_flag_high"`
	AnyFlagLow  []string `yaml:"any_flag_low"`
	AllNormal   []string `yaml:"all_normal"`
}
```

语义：`any_flag_high` 与 `any_flag_low` 之间是 OR，列表内部也是 OR；`all_normal` 仍是 AND。校验改为“两个列表至少一个非空”。不要引入通用表达式或按指标指定 flag 的 map——当前只有这一种低值需求，YAGNI。

`trigger` 不按成员年龄或性别设条件：低总蛋白/低白蛋白是化验指标，条目适用于所有成员；年龄只影响文案中的参考范围和生长建议。测试至少覆盖：低值单命中、高值旧条目仍命中、两个列表都空时加载失败、低值 + `all_normal` 不满足时不命中、高值与低值同时存在的 OR 行为。

## 6. 不能说的话

| 不能说的话 | 问题 | 依据 |
| --- | --- | --- |
| “白蛋白低就是营养不良” | 白蛋白是炎症标志，不是营养标志；单纯饥饿时常正常；营养不良按体重/生长/人体测量/摄入判断。 | S4、S5、S6 |
| “总蛋白低就是肝功能不好/肝硬化” | 低白蛋白非特异；急性肝病通常不低；PT/INR 更敏感；总蛋白还受球蛋白影响。 | S2、S6 |
| “白蛋白低就是肾病综合征” | 必须同时有肾病范围蛋白尿和低白蛋白或水肿；单次白蛋白不够。 | S9、S10、S11、S18 |

## 7. 证据边界

- **通用条目，不是儿科条目：** 本条目适用于所有成员；儿童、妊娠期、老年人的证据不能互相外推。年龄和生理状态只影响参考范围、生长/体重监测与风险背景，不改变“低蛋白非特异、先找医生”的结论。
- **年龄特异证据：** 儿童参考区间见 WS/T 780 [S1]；妊娠期血液稀释可使蛋白偏低（综述证据；妊娠期参考区间待验证）[S6]；老年人白蛋白可受年龄相关炎症/基础疾病影响（具体切点待验证）[S6]。这些只支持“可能不同”，不支持具体切点或诊断；未列出的年龄特异结论一律不写。
- **单次值 vs 趋势：** 白蛋白半衰期约 3 周，单次值反映一段时间平衡，不是当天变化 [S2]；异常应结合趋势与复查；体重/生长看系列测量 [S14]。
- **参考区间 vs 诊断切点：** 参考区间来自特定人群和方法，实验室使用前应验证 [S1]；低于下限只说明“与参考人群不同”，不等于疾病。
- **检验变异：** 溶血、脂血、胆红素干扰、输液侧采血、白蛋白方法差异可致假性结果 [S6]；单据范围优先，异常且意外时复查。
- **数据限制：** 产品通常没有症状、体格检查、尿蛋白、妊娠状态、生长曲线和用药信息；仅凭化验无法区分肝、肠、肾、营养或炎症，因此文案只能列可能性，不能给病因排序或诊断。
- **婴儿不在本条范围：** 本条不提供 <1 岁婴儿的喂养建议；出现低蛋白时应由儿科医生评估，不能套用成人/儿童通用饮食文案。
- **条目上限：** 匹配最多取 2 条；低蛋白条目与转氨酶条目可能同时命中，priority 要让临床更相关的条目先出。这是产品排序决定。
