# 05: 成员（B1）纵切

**What to build:** 家长在 App 里几十秒配好全家档案：给每个成员一个名字、标记是否孩子；孩子永远排在列表最前。这是所有后续归属、过滤、范围决策的地基。

**Blocked by:** 02（M0 契约冻结）, 04（工程骨架级纵切）。

**Status:** ready-for-agent

- [ ] App 建成员（显示名 + 是否孩子）、改名、改是否孩子；无删除入口（文案/交互不暗示可删）
- [ ] 成员列表孩子优先、其余按创建序（客户端排序）；空态引导创建
- [ ] 选中成员的上下文为后续票备好（时间线过滤、上传归属默认当前成员）
- [ ] API 集成测试（httptest + 编排 fakes）：建/列/改、存量无主报告与成员独立存在、排序口径
- [ ] fixtures 对账绿
