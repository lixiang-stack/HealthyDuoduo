# 08: 离线队列纵切

**What to build:** 在医院没有局域网的现实里拍照归档依然成立：照片进本地排队、回到家里网络自动补传、误拍可从队列剔除——"后端不可达"是一等状态而非报错弹窗。

**Blocked by:** 06（上传 + 时间线纵切）。

**Status:** ready-for-agent

- [ ] 后端不可达时选图进入本地队列卡片（排队中，回家自动传文案），不弹错误打断
- [ ] 队列项展示排序/失败状态，可删除（只删队列项本身，不碰已归档报告）、可手动重试
- [ ] 回到局域网（App 前台）自动重试；重试语义幂等（已归档的报告不重复出现，UI 呈现"已在档案"）
- [ ] 队列纯逻辑 reducer 单测：排队/失败/重试成功/重试失败/删除全迁移覆盖
- [ ] 验证环境可演示：断网 → 排队 → 恢复 → 自动补传进时间线
