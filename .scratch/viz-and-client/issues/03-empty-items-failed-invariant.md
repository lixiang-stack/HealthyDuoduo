# 03: 识别端不变量：空 items ⇒ failed

**What to build:** 一张拍糊了或只拍到标题的检查单照片，不会被伪装成"识别成功但什么都没有的报告"静默归档——它一律成为 failed 留痕，家长由此知道要重拍。这是识别端本期唯一改动点。

**Blocked by:** 02（M0 契约冻结）。

**Status:** ready-for-agent

- [ ] 识别端后处理规则保证：报告级别产出"成功且零指标项"不可能出现，一律判 failed 并给出失败原因
- [ ] 数据服务入库校验镜像同规则（双保险，绕过识别端直灌也挡住）
- [ ] 识别端 pytest 全绿；若存量 golden 出现"成功且空指标项"样本，按预期行为变更重基并逐条说明，其余 golden 逐字节不动
- [ ] 全链路验证：空白样例图走 ingest 后 status=failed，图像与 OCR 留痕保留
