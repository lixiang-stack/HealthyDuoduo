# 06: 上传 + 时间线纵切（在线路径）

**What to build:** 家长第一次把一张真实检查单变成档案里的卡片：验证环境选图、归属到成员、同步等待识别（约秒级）、时间线上出现带异常计数徽标的报告卡片。重复上传同一张图只归档一份；失败的图留痕但不骗人。

**Blocked by:** 05（成员纵切）, 03（空 items ⇒ failed 不变量）。

**Status:** ready-for-agent

- [ ] 上传前选择/确认归属成员；multipart 直传、服务端原子接收（无分片）、同步等待识别，等待体验可感知（进度/loading）且有超时提示
- [ ] 同步响应驱动页面：成功轻提示；识别失败展示后端错误信息
- [ ] 图像内容哈希幂等：重复上传返回已有报告并标记 duplicate，不重复归档
- [ ] 失败路径填充失败原因（流水线产出），时间线可见
- [ ] 时间线按当前成员过滤：报告类别、日期、状态文案（识别完成/待核对/识别失败）、按 flag 聚合计数徽标与"待核对 N 项"；failed 不计入待核对计数
- [ ] 日期缺失的报告不进时间线日期分组错位（null 日期展示不破坏排序）
- [ ] 空列表引导上传；加载与错误可重试
- [ ] API 集成测试：同步语义、幂等、失败留痕、成员过滤；fixtures 对账绿；真栈 e2e 冒烟扫通上传→时间线
