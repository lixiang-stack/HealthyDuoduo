# 07: 统计页图表接入（4 指标 × 3 图表）

**What to build:** 育儿 > 统计页接入 `charts.html` 的图表选型：指标（喂养 / 奶量 / 睡眠 / 尿布）× 图表类型（柱状 / 堆叠 / 折线），3 个 KPI、图注与选图建议；无数据空态；不新增导航层级，不重复放提醒卡片。

**Blocked by:** 01（护理事件契约）、02（导航壳）、03（当前孩子上下文）。

**Status:** ready-for-agent

## 验收清单

- [x] 统计页是育儿的二级视图（底部今天 / 统计），不升一级域、不加第三个底部 tab。
- [x] 4 个指标 tab：喂养 / 奶量 / 睡眠 / 尿布；每个指标有 3 个 KPI。
- [x] 3 个图表类型：柱状（每天多少）/ 堆叠（构成）/ 折线（趋势）；切换不离开统计页。
- [x] 柱状：每日总量，今天高亮；堆叠：喂养母乳/奶粉、睡眠夜间/白天、尿布尿/便/混合；折线：7 天趋势。
- [x] 单位、数值、日期标签正确；睡眠用小时、奶量用 ml、次数用次；图注说明「来自家长记录，不构成建议」。
- [x] 无数据：显示「还没有记录」+ 去今天页；只有一个数据点时照常渲染，不伪造趋势。
- [x] 统计页不出现提醒卡片；不读报告 / 指标趋势数据；不写分析快照。
- [x] 当前孩子切换后统计刷新到新孩子；跨孩子数据不混。
- [x] RNTL：指标 / 图表切换、KPI、今天高亮、空态、单点、无提醒卡片、孩子切换刷新。
- [x] Android 真机 smoke：390px 下标签不溢出、图表不抖动、切换不闪屏。

## 实现提示

- 复用 `prototype/charts.html` 的数据形状与图表渲染思路；不引入图表库，柱状 / 堆叠用 CSS，折线用 SVG。
- 图表数据来自 01 的读模型；没有正式 API 时用 adapter / fixture，字段与契约一致。
- 直方图不在本期；不要为「统计看起来丰富」给每个指标加三种以上图。
- 当前 7 天窗口下折线和柱状差异可能很小；保留图注说明折线更适合 30 天趋势，不要伪造趋势结论。
- 统计页不显示提醒卡片；提醒入口只在今天页。


## Comments

- 新增 `apps/mobile/src/care/careStats.ts`：7 个本机自然日窗口；喂养 / 奶量 / 睡眠 / 尿布四套读模型，各含每日总量、构成分段与 3 个 KPI。
