# 06: 提醒入口与本地通知

**What to build:** 提醒不是 tab：今天页保留「喂奶间隔提醒」卡片，点进提醒设置页；默认关闭、用户设定 2 / 3 / 4 小时间隔、只在本机调度本地通知。统计页不放提醒卡片。不做云推送、不承诺准时、不提供喂养建议。

**Blocked by:** 01（护理事件契约）、02（导航壳）、03（当前孩子上下文）。

**Status:** ready-for-agent

## 验收清单

- [ ] 今天页卡片显示开启状态与「上次/下次」；点击进入提醒设置；底部导航没有提醒 tab。
- [ ] 统计页不出现提醒卡片（移除 / 不添加）。
- [ ] 设置页：开关默认关闭；间隔 2 / 3 / 4 小时；从上次喂养开始计时；显示下次提醒时间。
- [ ] 开启时请求通知权限；权限拒绝时保持关闭并说明原因；不静默失败。
- [ ] 只调度本地通知（`expo-notifications` 或等价方案）；不接远程推送、不上传设备 token。
- [ ] 记录新的喂养后取消旧通知并按新时间重排；关闭提醒时取消全部已调度通知。
- [ ] 文案只陈述时间（「距上次喂养已 3 小时」），不写「该喂了」或喂养量建议。
- [ ] 已知限制写清：不承诺准时；Android 精确闹钟 / 省电策略、iOS 权限都会影响到达。
- [ ] RNTL：卡片 / 设置入口、默认关闭、间隔切换、权限拒绝、开关取消调度（mock notifications）。
- [ ] Android 真机 smoke：权限、调度、取消、重启 App 后状态一致。

## 实现提示

- 现有仓库未安装 `expo-notifications`；本票按 Expo SDK 58 的能力接入，改 `apps/mobile` 依赖与 app config。
- 调度是本地能力，不需要 Go / Python 改动；不要把提醒写进后端或分析快照。
- 上次喂养时间来自 01 的读模型；没有记录时显示「开启后从上次喂养开始计时」，不伪造时间。
- 睡眠 / 尿布提醒不在本票；页面上可标「以后」，不要做成可点击的假入口。
- 如果权限 / 精确闹钟验证不通过，降级为「只显示距上次喂养」事实卡片，不承诺通知。
