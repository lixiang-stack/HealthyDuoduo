# 02: B3 导航壳与路由（appbar 域 tab + 底部 contextual tabs）

**What to build:** 把 App 的主导航改成 B3：appbar 放一级域「日常 / 健康档案」，底部只放当前域的二级视图（日常：今天 / 统计；健康档案：报告 / 趋势）。先落导航壳、路由与占位页面，不接护理事件数据；孩子选择器由 03 接线。

**Blocked by:** None（可立即开始）。

**Status:** ready-for-agent

## 验收清单

- [ ] appbar 左侧「日常 / 健康档案」文本 tab：当前域加粗 + 2px 蓝色下划线；健康档案 tab 有待核对小圆点（由现有报告待核对计数派生）；右侧留当前孩子 `豆豆 ▾` 槽位（03 接线）。
- [ ] 底部 tab 随域变化：日常为今天 / 统计；健康档案为报告 / 趋势；不出现记录 / 提醒 / 设置 tab；最多两个底部 tab。
- [ ] 进入日常后底部不出现健康档案；进入健康档案后底部不出现日常。
- [ ] 域切换保留各自上次的二级 tab；点当前域的 appbar tab 回到该域根视图（日常 → 今天，健康档案 → 报告）。
- [ ] 路由：`/daily/today`、`/daily/stats`、`/health/reports`、`/health/trends`；报告详情、今日记录、提醒为栈页面，带返回且不显示底部 tab。
- [ ] 默认入口：有孩子成员 → `/daily/today`；无孩子成员 → `/health/reports`；首次启动可选「记录今天 / 查看健康档案」，之后记住上次域与二级 tab。
- [ ] 当前成员是成人时，日常入口引导选择孩子（03 完成前先显示占位说明，不把成人当护理目标）。
- [ ] Android 返回键：栈页面逐级返回；域切换不产生无法返回的伪栈。
- [ ] RNTL：appbar tab 激活 / 下划线 / 圆点、底部 tab 随域变化、二级 tab 状态保留、点当前域回根、默认入口、无孩子回健康档案。
- [ ] Android 真机 smoke：appbar 点击区域、下划线、圆点、底部 tab、返回键、390px 下不拥挤。
- [ ] 更新 `CONTEXT.md` 术语「日常 / 健康档案」；不改报告、核对、趋势的现有语义。

## 实现提示

- 用 Expo Router 的两个域分组承载：`/daily` 与 `/health`；各自有独立 tab layout，appbar 域 tab 在两组之间切换。不要用一个动态 tabs 数组硬塞两套底部 tab。
- appbar 是自定义 header，不依赖原生标题；二级视图名由底部 tab 承担，不在 appbar 重复。
- 各域二级 tab 状态用路由 / 局部状态保留；域切换用 `router.replace`，避免把域切换堆进返回栈。
- 健康档案待核对圆点复用现有报告摘要计数，不新增接口。
- 本票先放占位内容：今天 / 统计 / 报告 / 趋势可用现有组件或空态，避免被 01 阻塞。
