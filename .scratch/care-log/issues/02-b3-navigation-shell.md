# 02: B3 导航壳与路由（appbar 域 tab + 底部 contextual tabs）

**What to build:** 把 App 的主导航改成 B3：appbar 放一级域「日常 / 健康档案」，底部只放当前域的二级视图（日常：今天 / 统计；健康档案：报告 / 趋势）。先落导航壳、路由与占位页面，不接护理事件数据；孩子选择器由 03 接线。

**Blocked by:** None（可立即开始）。

**Status:** ready-for-agent

## 验收清单

- [x] appbar 左侧「日常 / 健康档案」文本 tab：当前域加粗 + 2px 蓝色下划线；健康档案 tab 有待核对小圆点（由现有报告待核对计数派生）；右侧留当前孩子 `豆豆 ▾` 槽位（03 接线）。
- [x] 底部 tab 随域变化：日常为今天 / 统计；健康档案为报告 / 趋势；不出现记录 / 提醒 / 设置 tab；最多两个底部 tab。
- [x] 进入日常后底部不出现健康档案；进入健康档案后底部不出现日常。
- [x] 域切换保留各自上次的二级 tab；点当前域的 appbar tab 回到该域根视图（日常 → 今天，健康档案 → 报告）。
- [x] 路由：`/daily/today`、`/daily/stats`、`/health/reports`、`/health/trends`；报告详情、今日记录、提醒为栈页面，带返回且不显示底部 tab。
- [x] 默认入口：有孩子成员 → `/daily/today`；无孩子成员 → `/health/reports`；首次启动可选「记录今天 / 查看健康档案」，之后记住上次域与二级 tab。
- [x] 当前成员是成人时，日常入口引导选择孩子（03 完成前先显示占位说明，不把成人当护理目标）。
- [x] Android 返回键：栈页面逐级返回；域切换不产生无法返回的伪栈。
- [x] RNTL：appbar tab 激活 / 下划线 / 圆点、底部 tab 随域变化、二级 tab 状态保留、点当前域回根、默认入口、无孩子回健康档案。
- [x] Android 真机 smoke：appbar 点击区域、下划线、圆点、底部 tab、返回键、390px 下不拥挤。
- [x] 更新 `CONTEXT.md` 术语「日常 / 健康档案」；不改报告、核对、趋势的现有语义。

## 实现提示

- 用 Expo Router 的两个域分组承载：`/daily` 与 `/health`；各自有独立 tab layout，appbar 域 tab 在两组之间切换。不要用一个动态 tabs 数组硬塞两套底部 tab。
- appbar 是自定义 header，不依赖原生标题；二级视图名由底部 tab 承担，不在 appbar 重复。
- 各域二级 tab 状态用路由 / 局部状态保留；域切换用 `router.replace`，避免把域切换堆进返回栈。
- 健康档案待核对圆点复用现有报告摘要计数，不新增接口。
- 本票先放占位内容：今天 / 统计 / 报告 / 趋势可用现有组件或空态，避免被 01 阻塞。

## Comments

**实现决定（2026-11-23）：**
- 首次启动的「记录今天 / 查看健康档案」选择屏未加：spec §4.3 写的是「可显示一次」，本票按「有孩子成员 → 日常今天；无孩子 → 健康档案报告」自动入口，并记住上次域与二级 tab。
- 健康档案圆点取当前成员的报告待核对计数；跨成员汇总留给后续有真实需求再加，不新增接口。
- 设置 / 管理成员入口移到报告页底部，避免 appbar 在 390px 下再挤一个动作；appbar 右侧只保留孩子槽位。
- `today-records` / `reminder` 先用根 Stack 占位页，确认不显示底部 tab；内容分别在 04 / 06 接入。
- 旧「家庭」首页 / 跨成员概览随 B3 移除：健康档案以成员 chips 进入单个成员的报告，不再保留成员卡待核对 / 异常汇总。若真实使用需要跨成员汇总，另开票恢复。
- 记住的是域的二级 tab（报告 / 趋势）；报告页内部的「按时间 / 按项目」`?view=` 不写入域记忆，切域回来落回报告的默认按项目视图。

**真机 smoke（2026-11-23）：** Android 16 真机（约 393dp 宽），Expo Go 58.0.5 + 隔离验收栈（`scripts/android-acceptance.sh --seed`）。已验证：appbar 日常 / 健康档案切换与下划线；健康档案圆点随当前孩子待核对出现、切成人后消失；底部今天 / 统计 / 报告 / 趋势随域变化；切域保留日常上次「统计」，点当前域回根；冷启动恢复上次「日常 > 统计」；报告按时间 / 按项目；报告详情 / 项目详情 / 今日记录 / 提醒为栈页，有返回且无底部 tab；成人当前成员显示选择孩子引导；设置页可写 Base URL 并通过健康检查。Expo Go 的浮动 Tools 按钮会遮住 appbar 右侧孩子槽位（dev-only 浮层，release 无此按钮）；报告页 `?view=` 切域后回到默认按项目，与本票记录的二级 tab 记忆边界一致。
