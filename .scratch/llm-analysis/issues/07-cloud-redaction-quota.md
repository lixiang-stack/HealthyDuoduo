# 07: 云端脱敏、LLM 客户端与配额

**What to build:** 分析请求能把脱敏后的证据包发给云端服务；超时、失败或配额用尽时自动降级到前两层；家长能看到今日剩余次数。

**Blocked by:** 04 分析事实层与结果页

**Status:** ready-for-agent

- [ ] 发送内容不含：姓名、出生日期、精确报告日期、机构、科室、医生、原图、OCR 原文（诊断与处理段落除外）、报告编号、主诉、现病史
- [ ] 发送内容含：指标规范名、数值、单位、参考范围、flag、相对时间、年龄段、诊断与处理原文、条目原文与 `source_ids`
- [ ] 单次 input 上限 8k tokens，超限先裁最旧证据点、不裁条目原文
- [ ] 单次 output 上限 1.5k tokens，超限截断并标注
- [ ] 每天每家庭 20 次，数值走配置
- [ ] 单次超时 30 秒
- [ ] 失败重试 1 次后省略解释层并标注原因，前两层不受影响
- [ ] 配额用尽时按钮仍可点击，解释层位置提示「今日额度已用完，事实与判读仍可用」
- [ ] 响应中返回 `used_today`、`limit_today`、`explanation_available`
- [ ] 单测覆盖脱敏字段清单、配额边界、超时降级
