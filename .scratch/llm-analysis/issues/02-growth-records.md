# 02: 生长记录与 BMI

**What to build:** 家长给成员录入身高体重和测量日期，标明来源是实测、体检单还是手输；成员列表显示最近一次记录与日期；系统用测量时点的值算 BMI，手输来源只显示数值，不输出超重 / 肥胖判定。

**Blocked by:** 01 成员模型扩展

**Status:** ready-for-agent

- [ ] 新增生长记录接受成员、测量日期、身高、体重（可单填）、来源
- [ ] 来源只接受 `measured` / `report` / `manual`
- [ ] 列表按测量日期降序
- [ ] BMI 用测量时点值实时计算，不缓存
- [ ] `source = manual` 时只输出 BMI 数值，不输出超重 / 肥胖标签
- [ ] 缺少 `birth_date` 或 `sex` 时不输出百分位
- [ ] App 提供生长记录表单，成员列表显示最近一次记录与日期
- [ ] HTTP 测试覆盖正常录入、非法来源、缺数据；RNTL 覆盖表单与列表
