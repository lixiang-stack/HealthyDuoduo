# 02: 生长记录与 BMI

**What to build:** 家长给成员录入身高体重和测量日期，标明来源是实测、体检单还是手输；成员列表显示最近一次记录与日期；系统用测量时点的值算 BMI，手输来源只显示数值，不输出超重 / 肥胖判定。

**Blocked by:** 01 成员模型扩展

**Status:** resolved

- [x] 新增生长记录接受成员、测量日期、身高、体重（可单填）、来源
- [x] 来源只接受 `measured` / `report`
- [x] 列表按测量日期降序
- [x] BMI 用测量时点值实时计算，不缓存
- [x] 来源只保留实测 / 体检单；手输来源移除（产品体验修订）
- [x] 缺少 `birth_date` 或 `sex` 时不输出百分位（成员模型两字段必填；百分位规则见 06）
- [x] App 提供身高体重表单，成员列表显示最近一次记录、来源与日期
- [x] HTTP 测试覆盖正常录入、非法来源、缺数据；RNTL 覆盖表单与列表
