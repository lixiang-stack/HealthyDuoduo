# 05: 框架层：肝功

**What to build:** 肝功分析里出现 R 值分型、转氨酶升高分级、AST/ALT 比；每个标签附带固定文案解释，例如「肝细胞型（转氨酶升高为主，碱性磷酸酶不明显升高）」。

**Blocked by:** 04 分析事实层与结果页

**Status:** ready-for-agent

- [ ] R 值按 `(ALT / ULN_ALT) ÷ (ALP / ULN_ALP)` 计算
- [ ] R ≥ 5 肝细胞型、R ≤ 2 胆汁淤积型、2 < R < 5 混合型；口径固定并注明来源
- [ ] 转氨酶分级：< 2×ULN 临界、2–5× 轻度、5–15× 中度、> 15× 重度
- [ ] AST/ALT 比直接计算
- [ ] 标签附固定解释文案，由代码渲染，不走模型
- [ ] ULN 缺失时不输出对应标签
- [ ] App 渲染框架层标签与解释
- [ ] 单测覆盖边界值：R 值 1.9 / 2.0 / 4.9 / 5.0，分级各档边界
