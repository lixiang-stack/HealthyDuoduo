## Comments

**实现（2026-11-03，分支 `llm-analysis-growth-facts`）**

- 纯领域层 `internal/analysis/framework.go`：R 值、转氨酶分级、AST/ALT 比值；只读事实层最新一份报告的有效点，ULN 用 `pipeline.RefRangeUpperBound` 从单据参考范围解析，缺 ULN 不输出标签。R 值只在至少一种肝酶高于 ULN 时分型，并要求固定解释与实际升高方向一致：肝细胞型要求 ALT 升高、胆汁淤积型要求 ALP 升高、混合型要求两者都升高；转氨酶未超过 ULN 时不输出分级，避免正常面板出现「胆汁淤积型 / 临界」。
- R 值固定口径：`R ≥ 5` 肝细胞型、`R ≤ 2` 胆汁淤积型、`2 < R < 5` 混合型；来源 AASLD / ACG 在标签 `sources` 中注明。
- 分级边界固定：`< 2×ULN` 临界、`2 ≤ x < 5×` 轻度、`5 ≤ x ≤ 15×` 中度、`> 15×` 重度；ALT / AST 取较高者，解释文案列出两者倍数。
- 标签附固定解释文案，App `FrameworkCard` 渲染标签、计算值、解释与来源。
- 单测覆盖 R 值 1.9 / 2.0 / 4.9 / 5.0、分级 1.9 / 2.0 / 4.9 / 5.0 / 15.0 / 15.1、ULN 缺失与 AST/ALT 比值。
