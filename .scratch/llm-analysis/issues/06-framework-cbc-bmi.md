# 06: 框架层：血常规与 BMI

**What to build:** 血常规分析出现贫血形态学分类和年龄段切点偏离；有生长记录时出现 BMI 与年龄性别百分位；手输身高体重只显示 BMI 数值不判超重。

**Blocked by:** 02 生长记录与 BMI, 04 分析事实层与结果页

**Status:** ready-for-agent

- [ ] BMI 用 WS/T 586—2018 性别年龄别界值判定
- [ ] 5–19 岁可用 WHO 2007 z-score
- [ ] `source = manual` 不输出超重 / 肥胖标签
- [ ] 缺 `birth_date` 或 `sex` 时不输出百分位
- [ ] App 渲染形态学分类、切点标签与 BMI 百分位
