# 04: 竖排回退只认格首数值——页脚散文格不再被抽成 value

**What to build:** `_vertical_value`（竖排回退：名称格正下方同列最近数值格）的候选门补上「数值 token 居格首（容许 ≤2 前缀字符）」，把「含数字的散文格」排除。真实缺陷：尿常规单的零碎片行（尿潜血）被页脚「实验室地址：…航天东路155号」喂成 value=155，raw_text 也把地址行吸进来。

- [x] 单测：散文格拒绝（155 不再入值）+ 正例（列内 `5.3 ↑` 照常吸收）

- [x] 内环：pytest 165 通过；本机 27 语料 check 回落至既有 5 项单位归一化陈旧（无新增漂移）

## Comments

**实现（分支 `recognizer-quality` 内单 commit；与 02/03 同 PR）**

- **候选门选择（有实测依据）**：先做消融——距离门不可行：本机语料合法竖排取值 dy 跨 54–698px（产筛「开放性神经管缺陷→2.5MOM」dy=698），而误吸的地址格 dy 仅 392px，**距离无法区分**。格形可以：全部合法取值都是「数值 token 居格首」的裸值（`33.25岁`/`2.5MOM`/`1:19879`/`5.3 ↑`/`0`），地址/电话类散文格的 token 在格中段（`实验室地址：…155号` start=10；`电话:876…` start=3）。取 `m.start() <= 2`（容许空白/箭头前缀），规则最小且不引入长度启发。
- **误伤评估**：阈值不是「残文长度」而是「token 居首」，`5.3 mIU/mL` 类长缀值不受影响；本机 27 语料 + samples 全量 golden + 真栈 16 报告实测零误伤（唯一变化即目标缺陷）。
- **语料证据**：`ua_07` 由共享栈真实报告（ocr_result 41）冻结后 `mask` 脱敏（人工复核 kept 行无姓名/证件/机构；PII 扫描 0 命中），golden 记修复后行为（尿潜血 value=null、raw_text 无地址行）。本机语料 `webwxgetmsgimg_13`（同版式旧照）按修复后行为刷新 golden。
- **与票 01 的关系**：该缺陷为**存量**（未改代码同样复现），非列归属改动的回归；由票 02 的度量在首轮真栈运行中抓出后立票。
- **披露**：尿液单的 OCR 本身有噪声（部分行值缺失），修复后以 `value=null`+partial 诚实呈现；「token 居首」仍属启发式，若未来出现格首即散文的古怪格（如 OCR 折行重排），将再次以语料证据迭代。
