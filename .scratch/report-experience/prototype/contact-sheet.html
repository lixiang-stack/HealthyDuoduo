趋势 → 原始图像：Q6 入口 / Q7 落点

任务：在 ALT 趋势详情里看到一个点，想核对「当时原始图像」上的那一行。
样例图像来自仓库脱敏样本 lft_02；原型截图隐藏了页眉 / 个人信息，生产展示用户自己的原图。
报告详情按项目组；组内「异常 / 未知」在前，「正常 / 未检测」在后（按你的 Q1 修正）。
推荐组合：Q6-A + Q7-A。 点卡上给一个明确的「查看原始图像」按钮；进入后直接看原图定位，识别值只作辅助。
理由：用户更相信原始图像；先把原图和蓝框给到，再让用户选择是否打开格式化报告。点行仍只切换选中点，不抢手势。

Q6 · 从趋势层怎么进入原始图像

A 点卡按钮 · 推荐
点行仍只切换选中点；选中后点上方「查看原始图像」进原图。手势不冲突，按钮明确、可测。代价是多一次点击。
B 点行直达 · 最快
点任一行直接进原图；选中点改用图上的小圆点。少一次点击，但「选点看值」和「进原图」抢同一个手势，图上圆点热区很小。
C 图上点浮层 · 图优先
点图上的圆点，在该点旁弹出摘要，再从浮层进原图。图与点的关系最直接；但浮层会盖住一部分曲线，圆点热区也小。

Q7 · 点「查看原始图像」后看到什么

A 全屏原图定位 · 推荐
原图是主体：自动裁到该指标所在行，蓝框标出 OCR 行；识别值放在下方作辅助。可切到整张检查单，或打开格式化报告。
B 报告内原图条带
完整报告 + 自动展开 96px 原图条带；复用现有 LineZoom / ocr_lines，实现最省。但图像是次要信息，条带太矮，不适合仔细看。
C 趋势层内原图预览
不离开趋势层，直接看原图条带；再决定「查看大图 / 打开完整报告」。上下不丢趋势上下文；但视口小，细节仍需大图。

Q7-A 的整张检查单状态

整张检查单 · 同一屏切换
从「定位到该项」切到整张检查单；页眉 / 个人信息已隐藏。生产里这里就是用户上传的整张原图，不需要隐藏。

实现边界（已核对代码）

  • ReportItem.ocr_lines 已有行号 + 四点多边形框；现有 apps/mobile/src/components/LineZoom.tsx 和 zoomCrop 已能裁到对应行，不需要新的识别能力。
  • TrendPoint 只有 report_id，没有 item_id。要定位到具体指标，需要按 name + unit 在报告详情里匹配，或给趋势点扩 item_id（契约变更）。
  • 原图 URL 来自报告详情；如果不想先进报告详情，需要轻量接口或在趋势点里带 image URL。首版建议复用报告详情加载。
  • 原图定位要处理 OCR 行缺失 / 框异常：退化为整张检查单，并提示「未能定位到原文行」；图像加载失败仍保留识别值。
  • 原型为压缩展示：只有定位项画成完整卡片，其余用紧凑行；生产仍用现有 ReviewItemCard，排序规则不变。
