# 分析结果页 · 2026-11-05 复核原型

## 这轮要选什么

不是继续微调文案，而是先决定**分析结果页的职责边界**：

- 它到底是“结论页”，还是“完整数据页”？
- 异常清单、历史趋势、BMI、报告范围，哪些必须留在结果页？
- “判据 / 依据 / 来源”要不要合并，用户看到的是一个入口还是三个入口？

三个方案都在 393×873 的目标尺寸下用同一组样例数据渲染：

- 小明 · 8 岁 · 肝功
- 2025-11-05 — 2026-11-05
- 4 项异常：ALT 83.5、AST 45、总蛋白 60.70、白蛋白 35.50
- 病历：2026-02-14，肝功能不全

## 对 8 个问题的判断

1. **“查看判据”和“查看依据”**
   - 判据 = 模型为什么把这条结论和这些数值连起来（bridge_text），是内部推理连接语。
   - 依据 = 这条解读引用的指南 / 标准。
   - 用户不需要区分这两层。原型统一收口为「查看来源说明」，把“为什么这样解读”放进来源说明或独立页，不再出现“判据”这个词。

2. **“这段不对”**
   - 这句话天然在暗示“结论可能不可信”，而且把反馈入口放在了结论旁边。
   - 改为中性的「反馈这段内容」；反馈分类、提交动作放进弹层。反馈是纠错入口，不是信任提示。

3. **原始 URL、打开、复制三件套**
   - 原始 URL 长度不可控，既不美观也不适合移动端阅读。
   - 原型不再展示 URL：来源行只显示「转氨酶升高分级（ACG 2016）」，点「查看来源说明」看人类可读说明；需要原文时只有一个「打开指南原文」按钮。复制从主界面移除，必要时长按或溢出菜单提供。

4. **ACG 2016 / AASLD**
   - 只在来源行保留“机构 + 年份 + 主题”的可读标签，例如「ACG 2016 · 美国胃肠病学会临床指南」。
   - 来源说明弹层用一句话解释这份指南是什么、这次用了它的哪条规则，再给「打开指南原文」。

5. **体格发育和肝功的关系**
   - 没有直接关系。BMI 是成员级指标，不是肝功判断的一部分；放在肝功结果页会和转氨酶分级抢权重。
   - 三个方案都从分析结果页移除 BMI，回到成员页看；如果产品坚持保留，也只能放在页面末尾作为“成员背景”，不能进入“指标分级”。

6. **窗口 / 历史 / 未参与为什么看起来矛盾**
   - 事实：2026-09-04 的总蛋白、白蛋白在窗口内，属于 4 项异常；用户看到的“未参与”主要是 2025-09-28 的旧点。
   - 2026-11-05 已新增通用低蛋白/白蛋白条目；新分析覆盖 4/4。旧快照仍显示“暂无对应解读”，原因不是日期，而是快照生成时还没有该条目。
   - 真正的矛盾来自“按指标稀疏扩展”：同一份 2025-09-28 报告，对总蛋白/白蛋白/GGT/球蛋白是“额外参考”，对胆红素/ALT/AST/ALP 又是“未参与”。页面把它呈现成两份全局报告清单，用户自然会问“到底用了没有”。
   - 修法不是再解释一遍，而是把口径拆开：
     - 本次判断只用窗口内结果；
     - 历史趋势是纵向视图，窗口前点逐指标标注「窗口前」，明确不参与异常判断；
     - 不再用“额外参考报告 / 未参与报告”这种全局二分，改为数据范围里逐指标说明。
   - 如果结果页不需要历史趋势，直接回「肝功」项目页看，这一整类矛盾就消失。这是方案 A 的核心。

7. **快照版本**
   - 用户不需要。三个方案都移除了 `rule_version / data_version / prompt_version / entry_versions`，只留在开发排查或后台。

8. **2/4、格式、判读**
   - 覆盖改为完整句：「4 项异常里，本次解读解释了 N 项」；新条目上线后为 4/4，旧快照仍为 2/4。
   - 列表统一用圆点；描述性段落不用圆点。
   - “判读”改为「指标分级」，副标题写「按公开标准，不是诊断」。

## 三个方案

### A · 结论页 + 回肝功项目页看明细（推荐）

- 结果页只回答“这意味着什么、下一步做什么”。
- 保留 4 行异常摘要，因为它是“2 项已解释 / 2 项未解释”的证据。
- 历史趋势、窗口前参考、全部指标回「肝功」项目页；BMI 回成员页。
- 最适合当前产品：分析页和肝功项目页不再重复，窗口矛盾从根上消失。
- 代价：用户想看趋势要再点一次；需要确保项目页入口明显。

### B · 单页分层，保留全部证据

- 结论、指标分级、异常、历史趋势、数据范围都在同一页。
- 历史默认折叠；窗口前点逐指标标注；数据范围逐指标解释“为什么用/不用旧点”。
- 适合“必须在一页内自证”的产品要求。
- 代价：页面仍然很长，信息密度高；历史趋势和项目页仍是重复的。

### C · 结论页 + 独立的“来源与数据”页

- 结果页极简：一句话结论、4 项异常、医生记录、操作。
- 第二页集中放“为什么这样解读”、来源说明、数据范围。
- 适合把“可信 / 可追溯”做成产品差异，但新增一层导航，且和项目页仍有部分重复。

## 已确认（2026-11-05）

用户选择 **方案 A**，并补充：

1. “可能原因”的内容也使用圆点，与“下一步 / 长期跟踪”保持一致。
2. 总蛋白、白蛋白仍在日期范围内；2026-11-05 已新增通用低蛋白/白蛋白条目，新分析覆盖 4/4；旧快照仍显示“暂无对应解读”，不是数据过期或窗口外。
3. 2026-11-05 进一步确认：转氨酶与低蛋白/白蛋白不再分两张卡，汇总成一张「本次解读」；蛋白文案精简为一段可能原因 + 三条下一步 + 四条生活建议。

其余决策同步确认：移除 BMI、移除快照版本、合并“判据 / 依据”为一个来源入口、来源不展示原始 URL、反馈文案改为「反馈这段内容」。

## 推荐

先选 A。
理由：当前最大的问题不是“解释不够多”，而是“结果页同时承担了解释、数据浏览、趋势浏览、范围审计四个职责”。A 把职责拆回：结果页负责结论，肝功项目页负责数据，成员页负责体格发育。

如果产品不接受“看趋势要跳页”，再选 B，并把历史趋势默认折叠。
